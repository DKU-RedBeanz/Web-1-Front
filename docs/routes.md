# 페이지·URL 표 — Sprint 2

관련 이슈: [Front #5](https://github.com/DKU-RedBeanz/Web-1-Front/issues/5)

| 화면 | 경로 | 상태 | 이동 |
|---|---|---|---|
| 홈 (스터디 조건 입력) | `/` | 구현 (#1) | → 추천 목록 |
| 스터디 목록 (추천 결과) | `/studies?goal=&level=&time=&mode=` | 구현 (#1) | → 상세, ← 조건 입력 |
| 스터디 상세 (로그인 필요) | `/studies/:studyId` | 구현 (#1) | ← 추천 목록, 비로그인 → 로그인 |
| 로그인 | `/login` | 구현 (#7) | → 회원가입, 아이디 찾기, 비밀번호 재설정 |
| 회원가입 | `/signup` | 구현 (#7) | → 로그인 |
| 아이디 찾기 | `/find-id` | 구현 (#7) | → 로그인, 비밀번호 재설정 |
| 비밀번호 재설정 | `/reset-password` | 구현 (#7) | → 로그인 |
| 마이페이지 | `/mypage` | 구현 (#7) | → 스터디 상세, 로그아웃 → 홈 |
| 없는 경로 | `*` | 구현 | → 홈 |

- 상단 헤더: 로고(홈) · 스터디 목록 · 로그인(비로그인) 또는 마이페이지(로그인)
- 비로그인 상태로 `/mypage`·스터디 상세에 접근하면 `/login`으로 이동하고, 로그인 후 원래 페이지로 돌아갑니다. (임시 로그인 상태 기준 가정, 실제 인증은 Back #7·#8 연결 시 교체)
- 화면 확인용 샘플 계정은 `src/data/sampleUser.ts`에 있습니다.
- 화면별 API 계약 초안은 [api.md](api.md)에 정리했습니다.

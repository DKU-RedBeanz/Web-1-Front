# 페이지·URL 표 — Sprint 2

관련 이슈: [Front #5](https://github.com/DKU-RedBeanz/Web-1-Front/issues/5)

| 화면 | 경로 | 상태 | 이동 |
|---|---|---|---|
| 홈 (스터디 조건 입력) | `/` | 구현 (#1) | → 추천 목록 |
| 스터디 목록 (추천 결과) | `/studies?goal=&level=&time=&mode=` | 구현 (#1) | → 상세, ← 조건 입력 |
| 스터디 상세 | `/studies/:studyId` | 구현 (#1) | ← 추천 목록 |
| 로그인 | `/login` | 뼈대 (UI는 #7) | → 회원가입, 아이디 찾기, 비밀번호 재설정 |
| 회원가입 | `/signup` | 뼈대 (UI는 #7) | → 로그인 |
| 아이디 찾기 | `/find-id` | 뼈대 (UI는 #7) | → 로그인 |
| 비밀번호 재설정 | `/reset-password` | 뼈대 (UI는 #7) | → 로그인 |
| 마이페이지 | `/mypage` | 뼈대 (UI는 #7) | → 홈 |
| 없는 경로 | `*` | 구현 | → 홈 |

- 상단 헤더: 로고(홈) · 스터디 목록 · 로그인 · 마이페이지
- 마이페이지의 로그인 필요 여부·리다이렉트는 인증 방식 확정(Back #8) 후 연결합니다.
